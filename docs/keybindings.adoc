= Keybindings

Complete keybinding reference for this configuration, generated from the live mapping table
(`nvim_get_keymap`) and curated by section. Last verified 2026-10-04.

toc::[]

== Notation

[cols="2,3"]
|===
|Notation |Meaning

|`<Space>`
|The leader key. Press `Space` and wait → which-key popup shows the menu tree live.

|`,`
|The *local* leader (used by plugins that opt into it; not bound globally).

|`<C-x>`
|Ctrl + x. `<M-x>` = Alt + x, `<S-x>` = Shift + x.

|n / x / o / i / c / t
|Modes: normal, visual+select, operator-pending, insert, cmdline, terminal.

|_(needs LSP)_
|Mapping only exists once a language server is attached to the buffer.
|===

== Flash — jumping around

`s` is deliberately *not* remapped in visual mode: there it keeps its native meaning
(delete selection, enter insert — same as `c`).

[cols="3,2,4"]
|===
|Keys |Mode |Action

|`s`
|n, o
|Flash jump — type two chars, then the label. In operator mode: `ds`, `ys`, `cs` style combos
work, e.g. `c` + `s` + chars to change through a jump.

|`S`
|n, o
|Flash treesitter select — pick a syntax node

|`S`
|x
|Flash jump in visual mode (the visual-mode remap; native `s` delete is preserved)

|`gS`
|n, o, x
|Flash treesitter select (works in visual too)

|`r`
|o
|Remote flash — operate from where the jump lands

|`R`
|o, x
|Flash treesitter search

|`f` `t` `F` `T`
|n, o
|Enhanced char motions — jump past the current line, labels appear on multiple matches

|`<C-s>`
|c
|Toggle flash labels while searching with `/`
|===

[NOTE]
====
`/` and `?` are plain search (flash's search mode is disabled); nvim-hlslens annotates them with
"match N of M" lenses and highlights all visible matches — see xref:#_searching[Searching].
====

== Where to change these

Every binding above comes from one of:

* `lua/plugins/snacks.lua` — pickers, explorer, toggles, zen/zoom, terminal
* `lua/plugins/flash.lua` — jump keys
* `lua/plugins/blink_cmp.lua` — chartoggle
* `lua/plugins/copilot.lua` — `<M-CR>` accept
* `lua/plugins/{grapple,grug-far,undotree,neoclip,img-clip}.lua` — tool keys, declared in an
  `AstroNvim/astrocore` `specs` block inside each file
* `lua/plugins/extras.lua` — diffview keys, hlslens search keys
* AstroNvim base (`%LOCALAPPDATA%\nvim-data\lazy\AstroNvim\lua\astronvim\plugins\`) —
  everything else; override in the `astrocore` specs pattern shown in the files above.
